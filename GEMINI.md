# CFD Trading ML & Quantitative Discovery: Project Constitution & Execution Rules

> **Project Mandate:** Rule-Based CFD Quantitative Research, Strategy Logic Template Discovery, and Automated Backtesting Engine for Expert Advisors.

---

## 1. Project Mission & Core Philosophy
1. **Rule-Based Strategy Discovery:** We do not write isolated, hard-coded EAs blindly. We build and benchmark modular **order-entry and exit logic templates** for EAs.
2. **Mass Parametric Sweeping:** Every strategy must be benchmarked across **hundreds to thousands of parameter combinations and market variations simultaneously**.
3. **True Robustness Over Curve-Fitting:** A strategy is only viable if it maintains a wide, stable parameter plateau across multiple years (2020–2025) and survives severe friction stress tests.
4. **Data Coverage:** Utilize all available historical tick/candlestick datasets (`/mnt/sdcard/Download/EA/XAUUSD_M1.csv.gz`, `EURUSD_M1.csv.gz`, and subsequent additions).

---

## 2. Standard Operating Procedures (SOP) & Coding Guidelines
1. **Anti-Lookahead Causal Integrity:**
   - Any signal generated by candle $i$ close MUST execute at candle $i+1$ open.
   - Intraday stops/targets must follow realistic sequence (conservative SL collision priority).
2. **Mandatory Institutional CFD Frictions:**
   - Gold: Spread $\ge \$0.25$, Commission $\ge \$6.00$/standard lot, slippage modeled.
   - Sizing: Standardized at 0.10 lots (10 oz Gold) across all comparison tables.
3. **Dual-Mode Performance Architecture:**
   - Use vectorized NumPy / Numba for sub-second sweeps of hundreds of sets.
   - Save full parametric sweep CSVs and JSON champion summaries for every run.

---

## 3. Autonomous Execution & Communication Rules
1. **Continuous Autonomy:** Work steadily and progressively without halting for trivial micro-approvals.
2. **Notification Cadence:** Deliver progress updates **every 30 minutes** OR **upon finishing each strategy/major milestone**.
3. **Token Optimization:** Avoid polling background commands repeatedly. Launch sweeps asynchronously and resume when notified.
4. **Task Cleanup Protocol:**
   - After each status update, check background tasks using `manage_task`.
   - If a task is finished (`DONE`/`EXITED`), kill/clean it up immediately to keep the workspace clean.
   - If a task is running normally toward its goal, leave it alone.

---

## 4. Mandatory Dual Backup Protocol
On completion of each strategy, sweep, or document:
1. **GitHub (`origin/main`):** `git add`, `git commit`, `git push origin main`.
2. **Phone Storage:** Mirror all files to `/mnt/sdcard/Download/EA/quant_strategy_discovery/`.
